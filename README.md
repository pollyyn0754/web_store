# Проект SkyStore

Проект создан как демонстрационное приложение для изучения основ Django и практики разработки с использованием современных инструментов.

## Описание

SkyStore — это веб-приложение на Django, представляющее собой каталог для хранения и продажи плагинов, примеров кода и других цифровых продуктов. 

## Установка

1. Клонируйте репозиторий:
```bash
git clone https://github.com/pollyyn0754/web_store
```

2. Установите зависимости:
```bash
pip install poetry
```
```bash
poetry install
```

3. Активация виртуального окружения:
```bash
poetry shell
```

4. Для работы с приложением секретный ключ, DEBUG и параметры подключения к базе данных хранятся в файле .env.

5. Запустите сервер:

```bash
python manage.py runserver
```
Приложение будет доступно по адресу: http://127.0.0.1:8000/

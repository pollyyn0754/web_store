# Проект SkyStore

Проект создан как демонстрационное приложение для изучения основ Django и практики разработки с использованием современных инструментов.

## Описание

SkyStore — это веб-приложение на Django, представляющее собой каталог для хранения и продажи плагинов, примеров кода и других цифровых продуктов. 

## Установка

1. Клонируйте репозиторий:
```bash
git clone https://github.com/pollyyn0754/web_store
```

2. Установите зависимости:
```bash
pip install poetry
```
```
poetry install
```

3. Активация виртуального окружения:
```bash
poetry shell
```

4. Для работы с приложением секретный ключ, DEBUG и параметры подключения к базе данных хранятся в файле .env.

5. Создайте базу данных PostgreSQL (например, через psql):
```
CREATE DATABASE skystore;
```

6. Примените миграции:
```bash
python manage.py migrate
```

7. Создайте группы ролей (обязательно для работы прав доступа):
```bash
python manage.py create_groups
```

8. Создайте суперпользователя:
```bash
python manage.py createsuperuser
```

9. (Опционально) Загрузите демонстрационные категории и продукты:
```bash
python manage.py add_products
```

10. Запустите сервер:

```bash
python manage.py runserver
```
Приложение будет доступно по адресу: http://127.0.0.1:8000/

Админ-панель: http://127.0.0.1:8000/admin/

## Функциональность

**Каталог продуктов**
* Главная страница с постраничным списком товаров (6 на страницу).
* Детальная карточка продукта: изображение, описание, цена, категория, даты создания и изменения.
* Просмотр товаров по категориям — отдельная страница для каждой категории.
* Ссылки на категории в футере и в карточках товаров.

**Управление продуктами (CRUD)**
* Создание, редактирование и удаление товаров доступно авторизованным пользователям.
* Продукт автоматически привязывается к создателю — поле owner.
* Владелец может редактировать и удалять только свои товары.
* Модератор (группа «Модератор продуктов») может удалять любые товары и отменять их публикацию.
* Статус публикации: Черновик (по умолчанию) / Опубликовано.

**Валидация формы продукта**
* Запрещённые слова в названии и описании (казино, криптовалюта, обман и др.) — проверка без учёта регистра.
* Цена не может быть отрицательной.
* Изображение: только JPEG/PNG, не более 5 МБ.

**Блог**
* Список опубликованных статей с пагинацией.
* Детальная страница статьи с автоматическим подсчётом просмотров.
* Поздравительное письмо на 100-м просмотре статьи.
* Управление статьями (создание/редактирование/удаление) — только для группы «Контент-менеджер» и суперпользователей.

**Пользователи**
* Регистрация по email (без username) с отправкой приветственного письма.
* Авторизация по email и паролю.
* Личный кабинет: аватар, телефон, страна.
* Кастомная модель пользователя (AbstractUser без username).

**Контакты**
* Страница с контактными данными компании (страна, ИНН, адрес).
* Форма обратной связи (имя, телефон, сообщение).

**Кэширование**
* Кэширование детальной страницы продукта (cache_page, 15 минут).
* Кэширование списка продуктов категории (cache.set, 10 минут).

## Роли и права

| Роль    | Права                                            |
|---------|--------------------------------------------------|
| **Аноним** | Просмотр каталога, блога, страницы контактов, регистрация, вход |
| **Авторизованный пользователь** | Всё выше + создание товаров, редактирование и удаление своих товаров, профиль |
| **Модератор продуктов** | Всё выше + удаление любых товаров, отмена публикации |
| **Контент-менеджер** | Управление публикациями блога                    |
| **Суперпользователь** | Полный доступ, включая админ-панель              |

## Management-команды

| Команда                        | Назначение                                                                                                                                                                      |
|--------------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| python manage.py create_groups | Создаёт/обновляет группы «Модератор продуктов» и «Контент-менеджер» с нужными правами. Безопасно запускать повторно.                                                            |
| python manage.py add_products  | Удаляет все категории и продукты и загружает фикстуру catalog/fixtures/catalog_fixture.json. <br/>⚠️ Деструктивная операция — используйте только для инициализации демо-данных. |

## Тестирование

Проект покрыт тестами для ключевых сценариев:
* **Каталог:** валидация формы (запрещённые слова, отрицательная цена, формат и размер изображения), права на редактирование/удаление (владелец, модератор, сторонний пользователь).
* **Блог:** права доступа к созданию/удалению статей (аноним, автор без прав, контент-менеджер, суперпользователь).
